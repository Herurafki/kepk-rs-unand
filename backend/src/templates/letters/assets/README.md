# Aset Template Surat KEPK

Letakkan gambar kop surat resmi di folder ini dengan nama:

- `kop-surat.png` — kop surat lengkap yang mencakup lambang Universitas Andalas dan logo Rumah Sakit Universitas Andalas.
- `logo-akreditasi.png` — logo akreditasi, jika ingin ditampilkan terpisah pada bagian bawah surat.

## Lokasi folder

`src/templates/letters/assets/`

Gambar kop surat sebaiknya berupa PNG dengan latar transparan dan rasio horizontal. Generator PDF membaca file tersebut secara otomatis. Jika `kop-surat.png` belum tersedia, template menampilkan kop sementara.

Area tanda tangan dan stempel tetap kosong untuk ditandatangani secara manual.
